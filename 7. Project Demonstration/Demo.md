# LegalEase - Project Demonstration

## 1. Application Name

LegalEase - AI Powered Legal Document Generator

## 2. Demonstration Steps

### Step 1

Open the LegalEase Streamlit application.

### Step 2

Select the required legal document type.

Available options:

- Rental Agreement
- Non-Disclosure Agreement
- Offer Letter
- Affidavit

### Step 3

Enter the user's name.

### Step 4

Enter the address.

### Step 5

Enter the additional information required for the selected document.

### Step 6

Click the "Generate Legal Document" button.

### Step 7

The application sends the request to Gemini AI.

### Step 8

The generated document is displayed on the screen.

### Step 9

Review the generated document.

### Step 10

Use the "Download Document" button to save the generated document.

## 3. Expected Output

The application should generate a structured legal document containing:

- Document title
- Relevant sections
- Clauses
- Terms and conditions
- Signature section
- Legal review notice

## 4. Testing During Demonstration

The following cases should be demonstrated:

### Test Case 1

Valid user information.

Expected result:

Document should be generated successfully.

### Test Case 2

Empty name.

Expected result:

The application should display an error message.

### Test Case 3

Empty additional information.

Expected result:

The application should request the required information.

### Test Case 4

Invalid or missing API configuration.

Expected result:

The application should display an appropriate warning or error.

## 5. Demonstration Conclusion

LegalEase successfully demonstrates the use of Generative AI for
assisting users in creating basic legal document drafts.

## 6. Disclaimer

The generated documents should be reviewed by a qualified legal
professional before being used for official purposes.
